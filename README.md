# retro-bowl

About This Project
This project is a fan-made modification and is not the official version of Retro Bowl.

It has been created strictly for fun and includes custom features, tweaks, and built-in cheats. Please note that this version is completely unofficial and is not endorsed by, affiliated with, or supported by the original developers, New Star Games.

Looking for the Real Retro Bowl?
If you want to support the original creators and enjoy the authentic, official Retro Bowl experience, you can find and play the official game on the following platforms:

iOS: Search for Retro Bowl on the Apple App Store.

Android: Search for Retro Bowl on the Google Play Store.

Nintendo Switch: Available on the Nintendo eShop.

Web Browser: Play officially on web platforms such as Poki.
